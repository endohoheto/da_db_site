# 鬼ノノグラム

浅倉大介にまつわる名前が絵になるノノグラム(お絵かきパズル)。
スマホのホーム画面に置いて、アプリのように使える Web アプリ(PWA)です。

- 絵はすべて**文字だけ**。アーティスト名・曲名・盤名・ツアー名をドット文字で組んでいます。ロゴやジャケットは使いません
- 解くと、何の名前だったかがわかります。解いた問題は一覧に絵と名前で並びます
- 答えは必ず1つ。**標準**は行と列の理詰めだけで、**鬼**は「仮に塗って矛盾を探す」読みが要ります
- 文字の形によっては推論だけで1つに絞れないので、最初から見せるマス(ヒント)を最小限だけ置いています
- サーバー不要。オフラインでも動く

## 使い方(スマホ)

1. 公開URLを Safari / Chrome で開く
2. iPhone: 共有ボタン →「ホーム画面に追加」/ Android: メニュー →「アプリをインストール」
3. ホーム画面のアイコンから起動

途中経過は端末に自動保存されます。機種変更のときはメニューの「引き継ぎ」でコードを作って移してください。

## 問題を増やす

言葉は2か所から取ります。同じ文字列は `words.json` が優先です。

| ファイル | 中身 |
|---|---|
| `data/words.json` | 手で選んだ言葉。`layout` で改行位置を指定できる(例: `"コタニ\nキンヤ."`) |
| `data/db-words.json` | クレジットDBから書き出した言葉。DB側で `npm run nonogramwords` を実行すると、隣にあるこのリポジトリへ書かれる |

```bash
npm install                 # ドット文字のフォント(ビルド時だけ使う)
npm i -D playwright         # 文字を描くのに使う。未導入なら
npm run build:puzzles       # data/ → puzzles.json
npm run build:puzzles -- "コタニキンヤ."   # 1語だけ試して絵を表示(puzzles.json は書かない)
npm test                    # 全問の「答えが1つ」を別の探索で数え直す
```

**問題を変えたら `sw.js` の `VERSION` を上げる。** 上げないと、ホーム画面のアプリに古い問題がキャッシュから配られ続けます。

### 問題の作り方

1. 言葉を Fusion Pixel Font(8/10/12px、OFL)で描く。10倍で描いて各ドットの中心を読むので、にじみが入らない
2. 「文字の大きさ × 改行位置 × 太字にするか」の候補を作る(盤面は最大32マス、収まらない長い名前だけ40マス)
3. 各候補を、行・列ごとの理詰め → 仮置き の推論で解く。最後まで埋まれば答えは1つ
4. 埋まらなければ、「見せると推論でいちばん多く埋まるマス」を1つずつヒントにする
5. 読みやすさ(大きい文字・少ない行・そろった行の長さ)とヒントの少なさで選ぶ

## 公開

クレジットデータベースの入口ページ(`da_db_site`)の `nonogram/` フォルダに置いて、
`https://endohoheto.github.io/da_db_site/nonogram/` で公開しています。ビルドの手順はありません(`puzzles.json` はコミットしておく)。

## 開発

```bash
npm run serve     # http://localhost:8080
npm run e2e       # 画面の動作確認(Playwright が必要)
```

| ファイル | 役割 |
|---|---|
| `gen.js` | 行ソルバーと推論。画面(矛盾した行の表示)と問題作りの両方で使う |
| `app.js` | 画面と操作。盤面は canvas 1枚で描く |
| `app.css` | 見た目。上の帯・盤面・道具帯の3段 |
| `sw.js` | オフライン用キャッシュ |
| `tools/build-puzzles.mjs` | 言葉から問題を作る |
