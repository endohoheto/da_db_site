# 鬼ノノグラム

浅倉大介にまつわる名前が絵になるノノグラム(お絵かきパズル)。
スマホのホーム画面に置いて、アプリのように使える Web アプリ(PWA)です。

- 絵はすべて**文字だけ**。アーティスト名・曲名・盤名・ツアー名をドット文字で組んでいます。ロゴやジャケットは使いません
- 解くと、何の名前だったかがわかります。解いた問題は一覧に絵と名前で並びます
- 答えは必ず1つ。**標準**は行と列の理詰めだけで、**鬼**は「仮に塗って矛盾を探す」読みが要ります
- 文字の形によっては推論だけで1つに絞れないので、最初から見せるマス(ヒント)を最小限だけ置いています
- サーバー不要。オフラインでも動く

## 使い方(スマホ)

1. 公開URLを Safari / Chrome で開く
2. iPhone: 共有ボタン →「ホーム画面に追加」/ Android: メニュー →「アプリをインストール」
3. ホーム画面のアイコンから起動

途中経過は端末に自動保存されます。メニューの「アカウント」でIDとパスワードを登録すると、別の端末でも続きから遊べます(設定は `server/README.md`)。登録しない場合は、「引き継ぎ」のコードで移せます。

## 問題を増やす

出題するのは `data/words.json` の言葉だけです。

| ファイル | 中身 |
|---|---|
| `data/words.json` | 出題する言葉。`layout` で改行位置を指定できる(例: `"コタニ\nキンヤ."`) |
| `data/db-words.json` | クレジットDBから書き出した**候補**。DB側で `npm run nonogramwords` を実行すると書かれる。セトリの「MC」やイベント名のような絵にならないものも混ざるので、**選んで words.json に移す** |
| `data/published.json` | 公開済みの問題の台帳(key と形の指紋)。ビルドが書き足し、テストが突き合わせる |

```bash
npm install                 # 文字のフォント Noto Sans JP(ビルド時だけ使う)
npm i --no-save playwright && npx playwright install chromium   # 文字を描くのに使う。未導入なら
VARIANTS=3 npm run build:puzzles   # words.json に足した言葉の分だけ作り、後ろに足す
npm run build:puzzles -- "コタニキンヤ."   # 1語だけ試して絵を表示(puzzles.json は書かない)
npm test                    # 全問の「答えが1つ」の数え直しと、公開済みの問題が変わっていないかの確認
```

**公開した問題は作り直さない。** 遊びかけの盤面は key(名前#番号)ごとに縦×横のマスで預かっているので、
形が1マスでも変わると途中経過が壊れます。一覧の No. も並び順なので、途中に挟むと番号がずれます。
ビルドは既存の問題をそのまま残して後ろに足すだけで、変わっていればテストが落ちます
(`REBUILD=1` で全部作り直せますが、公開後は使わないこと)。

**足すのは小分けに。** 1問およそ4KBで、`puzzles.json` は起動のたびに読み直され、一覧には全問のカードが並びます。
今は1語3問(`VARIANTS=3`)で、数十語ずつ足しています。

**問題を変えたら `sw.js` の `VERSION` を上げる。** 上げないと、ホーム画面のアプリに古い問題がキャッシュから配られ続けます。
ランキングの保存係は問題一覧を6時間覚えているので、足した問題のクリアがランキングに載るのは最大6時間後です
(記録は端末から毎回まとめて送られるので、失われはしません)。

### 問題の作り方

1. 言葉を Noto Sans JP の太字(700/900)で、1文字20〜32マスに描く。8倍で描いて、各マスの塗られている割合が半分を超えたら塗りにする。線が2〜4マスの太さになるので字として読め、数字の手がかりも多い
2. 改行は必ず2〜4行(1行の並びは形を先読みしやすい)。文字ごとの上下のずらし方は 波・階段・ジグザグ・乱数 × 小・大
3. 各候補を推論で解き、難しさを4段階に分ける
   - やさしい: 行と列の理詰めだけで、往復8回以内
   - ふつう: 行と列の理詰めだけで、往復が多い
   - むずかしい: 仮置きが要る(または最初から見せるマスがある)
   - 鬼: 見せるマスなしで、仮置きが25回以上要る
4. 段階ごとに、改行かずらし方が違う問題を選び、1語あたり最大7問を残す(キーは「名前#番号」)

試したがやめたもの: 8〜16ドットのドット文字(線が1マスで、答えが1つに絞れないか読めない)、太字加工・影付き(線がくっついて字が崩れる)、白抜き(易しすぎる)。

## 公開

クレジットデータベースの入口ページ(`da_db_site`)の `nonogram/` フォルダに置いて、
`https://endohoheto.github.io/da_db_site/nonogram/` で公開しています。ビルドの手順はありません(`puzzles.json` はコミットしておく)。

## 開発

```bash
npm run serve     # http://localhost:8080
npm run e2e       # 画面の動作確認(Playwright が必要)
```

| ファイル | 役割 |
|---|---|
| `gen.js` | 行ソルバーと推論。画面(矛盾した行の表示)と問題作りの両方で使う |
| `app.js` | 画面と操作。盤面は canvas 1枚で描く |
| `app.css` | 見た目。上の帯・盤面・道具帯の3段 |
| `sw.js` | オフライン用キャッシュ |
| `tools/build-puzzles.mjs` | 言葉から問題を作る |
