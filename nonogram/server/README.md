# ID・パスワードで途中経過を預かる仕組み

保存先は Google スプレッドシート「ID」。そこに付けた Apps Script(`Code.gs`)がウェブアプリとして受け付ける。
データベース本体(da_db)とは別のものなので、データベースには影響しない。

## 準備(最初に一度だけ)

1. スプレッドシート「ID」を開く
2. メニューの「拡張機能」→「Apps Script」
3. 最初から入っている文字を全部消して、`Code.gs` の中身を貼る
4. 保存(フロッピーのマーク)
5. 右上の「デプロイ」→「新しいデプロイ」→ 歯車 →「ウェブアプリ」
6. 「次のユーザーとして実行」は **自分**、「アクセスできるユーザー」は **全員**
7. 「デプロイ」。許可を求められたら自分のアカウントで許可する
   (「このアプリは確認されていません」と出たら「詳細」→「(安全ではないページ)に移動」)
8. 出てきた「ウェブアプリ」の URL を `../config.js` の `NONO_SYNC_URL` に入れる

`Code.gs` を直したときは、貼り直して保存してから「デプロイ」→「デプロイを管理」→ 鉛筆 →
「バージョン」を「新バージョン」→「デプロイ」で、同じ URL のまま更新する
(「新しいデプロイ」にすると URL が変わる)。

ランキングを足した版から、公開中の問題一覧(`puzzles.json`)を読みに行くようになった。
そのため更新のときに、もう一度「許可」を求められる(「外部サービスへの接続」)。最初と同じように許可する。

## 預かるもの

シート `users` に1人1行。

| 列 | 中身 |
|---|---|
| id | ID(小文字) |
| salt / hash | パスワードを元に戻せない形にしたもの。アプリの中で一度ハッシュにしてから送り、ここで塩を足して2000回ハッシュにする |
| updated / created | 最後に預けた時刻 / 登録した時刻 |
| size / data… | 途中経過(アプリが圧縮した文字列)。1セル45,000文字ずつ横に並べる |

同じIDでパスワードを10分に10回まちがえると、しばらく受け付けない。

シート `players` に表示名(ランキングに出る名前)。ランキングに出すのはこの名前だけで、IDは返さない。

| 列 | 中身 |
|---|---|
| id | ID |
| name | 表示名(1〜12文字、ほかの人と重複不可、IDと同じは不可) |
| created | 登録した時刻 |

シート `clears` に、1人1問1行で解いた記録。

| 列 | 中身 |
|---|---|
| id / key | ID / 問題(名前#番号) |
| level | 難しさ。端末の言い値ではなく、公開中の `puzzles.json` から引く |
| ms | まちがいチェックなしで解いた最速タイム(ミリ秒)。1マス0.02秒より速いものは入れない |
| first / best_at | 初めて解いた時刻 / 最速を出した時刻(同じタイムなら先に出した人が上) |

困った表示名があったら、`players` の name を書き換えるか、その行を消せばランキングから消える。

## 確かめ方

`npm test` の `test/server.test.mjs` が、Apps Script の代わりの部品(`scripts/gas-mock.mjs`)で `Code.gs` をそのまま動かして確かめる。
`npm run e2e` は、2台の端末で同じIDを使って続きから遊べることを確かめる。
