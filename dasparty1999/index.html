DA’s Party 1999
収録対照表

1999年のDA’s Party 5公演のセットリストを1曲ずつ並べ、Viewsicでの放送・当時のVHS・2026年10月28日発売のBlu-ray『DA’s Party 1999 SPECIAL EDITION』に入っているかを突き合わせました。

表の「放送」「VHS」は ● が収録あり、― がなし。「BD」は収録されているディスクです。注記はページの最後にまとめています。

曲目には無いが収録

  • 1999.2.14Blind Game again
  • 1999.2.14THUNDERBIRD
  • 1999.2.14GALAXY GANG

VHSのクレジットにもBDの曲目にも載っていないが、VHSに入っている3曲。 DISC 1 は VHS と同じ内容なので、BDにも入る。

VHS と BD の曲目

代々木の3公演はVHSが無く、DISC 3の全曲が初商品化。 VHS のクレジットと BD の曲目は、2/14(DISC 1・16曲)も 8/29(DISC 2・11曲)も曲名・曲順とも同じ。

DISC 3 はどの回の映像か

ほとんどが 1/1 Happy New Year の放送から。 FATE WEATHER と Shining Collection は 12/31 Grand Finale、 DA’s Party 2000 は 12/31 Count Down から。 THE ELECTROMANCER は両日で放送があり、発売後に確認。 放送があってDISC 3に無いのは 1/1 の「1000年の誓い」だけ。

注記

  1. VHS には、曲が編集されて入っているものが多くあります。BD の DISC 1・2 は、2/14・8/29 の VHS と曲目・曲順が同じで、VHS と同じ内容です。
  2. 2/14 と 8/29 は、ブログの記載により全曲が Viewsic で中継されています。
  3. 8/29 の放送では、年末の回と同じく、オープニングと各出演者の最初にナビゲーターが入ります。BD に入るかは分かりません。ただし、BD に1曲も入っていない出演者の前のものは入りません。
  4. メドレーなど、公式では1曲になっているところは、公式の曲名に番号を付け、曲はその下に内訳として並べています。まとめて1曲と数えます。公式に1曲としての名前がないもの(2/14 のピアノメドレー)は Pf Solo としています。映像のみ(MV)の行は曲に数えていません。
  5. 代々木の3公演は、当時 VHS が出ていません。DISC 3 は公式に「Viewsic が放送した映像」とあり、各曲がどの回の映像かは、ブログの放送記録から割り出しました。同じ曲を別の回の放送から収録している行は「BD」を ― にし、曲名の下に収録元の回を書いています。
  6. 曲名・公演名・アーティスト名は、ソニーミュージック公式の表記に合わせています。公式に出てこないものはデータベースの表記です。公式と曲名が違う曲には、公式の曲名を「BD表記」として添えています。
  7. BD の内容は、発売後に映像で確認して追記します。
