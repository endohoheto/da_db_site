DA’s Party 1999
収録対照表

1999年のDA’s Party 5公演のセットリストを1曲ずつ並べ、Viewsicでの放送・当時のVHS・2026年10月28日発売のBlu-ray『DA’s Party 1999 SPECIAL EDITION』に入っているかを突き合わせました。

表の ● はあり、― はなし。「BD」の欄は収録されているディスクです。注記はページの最後にまとめています。

VHS と BD の曲目

2/14(DISC 1・16曲)と 8/29(DISC 2・11曲)は、当時の VHS と曲目・曲順が同じ。 代々木の3公演は VHS が出ておらず、DISC 3 の全曲が初の商品化。

DISC 3 はどの回の映像か

DISC 3 は Viewsic の放送と同じ内容。 ほとんどが 1/1 Happy New Year の映像で、 FATE WEATHER と Shining Collection は 12/31 Grand Finale、 DA’s Party 2000 は 12/31 Count Down の映像。

注記

  1. VHS には、編集されて入っている曲が多くあります。
  2. 表の「放送」は Viewsic の放送です。2/14 と 8/29 は全曲が中継されました。「別編集でOAあり」は、ほかの番組で別に編集された映像が放送されたもので、かっこ内は放送日・局・番組名です。
  3. 8/29 の放送では、オープニングと各出演者の前にナビゲーターが入ります。VHS・BD には入っていません。
  4. メドレーなど BD で1曲になっているものは、BD の曲名で1曲と数え、その下に曲を並べています。2/14 のピアノメドレーは BD に1曲としての名前がないため、Pf Solo としています。映像のみ(MV)は曲に数えていません。
  5. 同じ曲を代々木の複数の回で演奏している場合、BD に入っているのは放送された回の演奏です。ほかの回の行は「BD」を ― にし、収録されている回を曲名の下に書いています。
  6. 曲名・公演名・アーティスト名は、ソニーミュージック公式の表記に合わせています(公式にないものはデータベースの表記)。公式と曲名が違う曲には「BD表記」を添えています。
